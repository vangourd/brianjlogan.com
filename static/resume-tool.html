$ resume-encrypt

Bundles an HTML fragment + a PDF into one AES-256-GCM blob (PBKDF2-SHA256, 250k iters), BRZ2 envelope, ready to upload to /encrypted-resumes/<id>.bin. The /resume page injects the HTML inline and offers the PDF as a download.

1. HTML fragment (inline render)

2. PDF (download link)

3. Passcode

4. ID

5. Encrypt

encrypted bundle ↓ download <id>.bin

Upload to s3://brianjlogan/encrypted-resumes/<id>.bin via tools/upload-asset.sh <path> encrypted-resumes/<id>.bin --no-cache.
